# Pecut AI

A joke desktop app (Windows / Linux / macOS) that shows a little foreman **whipping your AI agent**
every time a Claude Code prompt is running. CTARR!

- 5 original animation styles: Pixel Art 8-bit, Notebook Doodle, Flat Cartoon, Neon Synthwave, Manga Comic
- Whip sounds, random nagging lines, lash counter, tray icon, draggable always-on-top window
- Two languages: Bahasa Indonesia and English (or Mixed)
- All art and sound is generated by code (`tools/`) - no downloaded assets

## How it works

Pecut AI uses [Claude Code hooks](https://docs.claude.com/en/docs/claude-code/hooks):

1. `UserPromptSubmit` runs `hook.py start`, which writes a marker file in `~/.pecut_ai/sessions/`.
2. `PostToolUse` refreshes the marker while the agent keeps working.
3. `Stop`, `Notification` or `SessionEnd` deletes the marker.
4. The app watches that folder. While at least one marker exists, the whipping goes on.

Markers older than 10 minutes are cleaned up automatically (e.g. if you pressed Esc mid-answer).

## Install

```bash
pip install -r requirements.txt
python -m pecut_ai.installer install     # adds the hooks to ~/.claude/settings.json (backs it up first)
python run_pecut.py                      # start the app (lives in the system tray)
```

Try it without an AI:

```bash
python run_pecut.py --demo
```

Remove the hooks:

```bash
python -m pecut_ai.installer uninstall
```

## Options

Right click the animation or the tray icon for: animation style (random per prompt or fixed),
language, size, whip speed, opacity, volume, sound / text / counter toggles, manual whip,
reset position / counter, and install / remove hooks. Double click the animation to switch style.

Settings are stored in `~/.pecut_ai/settings.json`.

## Performance

Pecut AI is built to stay out of your way:

- Every animation frame is pre-rendered once, so playing a frame is a single image copy.
- Only the animation area is repainted, and nothing runs while the window is hidden.
- Sound uses the OS player (winsound / afplay / pw-play, paplay, aplay) instead of a media framework.
- Session changes are picked up by a folder watcher instead of fast polling.

Measured on Windows 11 (Python 3.11, PySide6 6.11), share of one CPU core:

| State | Before | Now |
|---|---|---|
| Idle (no AI running) | 0.1% | 0.0% |
| Whipping | 20.3% | about 2-5% |

"Battery saver" in the menu halves the frame rate (12 fps) if you want it even lighter.
